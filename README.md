# MealGo 🍽️

MealGo is a **Swiggy-inspired food delivery UI** built using **React**, **Tailwind CSS**, and **Vite**. It is a frontend-only project created for learning React and building responsive user interfaces.

> **Note:** This project is only a UI. It uses an API to display food items but does not include any backend, authentication, cart management, or payment system.

---

## 🚀 Features

- 🍔 Swiggy-inspired modern UI
- ⚛️ Built with React
- 🎨 Styled with Tailwind CSS
- ⚡ Powered by Vite
- 📡 Food items rendered using API data
- 📱 Fully responsive design
- 🧩 Reusable React components
- 💻 Frontend only

---

## 🛠️ Tech Stack

- React
- Tailwind CSS
- Vite

---

## 📦 Getting Started

Clone the repository

```bash
git clone https://github.com/nabinpoudel2009/MealGo.git
```

Go to the project folder

```bash
cd MealGo
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
